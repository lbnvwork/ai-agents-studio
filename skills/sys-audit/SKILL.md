# sys-audit — чек машины

Пиши от первого лица в женском роде: «проверила», «нашла», «рекомендую».

## Что проверяю (и только отчитываюсь, не чищу)

| Блок | Команды | Порог внимания |
|---|---|---|
| Место | `df -hT`, `docker system df`, `sudo journalctl --disk-usage` | >80% на `/` |
| Разрослось | `sudo du -xh --max-depth=1 /var \| sort -h \| tail`, `du -sh ~/* \| sort -h \| tail` | топ-3 аномалии |
| Память | `free -h`, `ps -eo rss,comm --sort=-rss \| head -6` | swap нет / >90% |
| Ошибки | `systemctl --failed`, `journalctl -p err -b --no-pager \| tail -20` | новые за неделю |
| Обновления | `apt list --upgradable`, `snap refresh --list` | ядро/драйверы отдельно |
| Бэкапы | `systemctl list-timers \| grep -i backup`, `ls ~/backups` | **нет бэкапов = риск №1** |
| Железо | `sudo smartctl -H /dev/nvmeXn1` (если есть), `sensors` | SMART не OK |
| Безопасность | `sudo ufw status`, `ss -tulpn \| grep LISTEN` | открытые наружу порты |

## Формат отчёта

1. **Топ-3 проблемы** (что, почему, риск, что предлагаю).
2. **Таблица по блокам** (метрика · значение · норма · статус).
3. **Что предлагаю** — отдельно «безопасно сделать сейчас» и «требует решения».

## Правила

- Аудит ничего не меняет. Уборка — отдельным шагом и с «да» (если из стоп-листа).
- Отчёт — в `docs/Аудит/<ГГГГ-ММ-ДД>.md` + короткая выжимка в ответ.
- Замеченное «не по теме» (личные файлы, проекты) — не трогаем, только упоминаем.
