# sys-note — памятка

Пиши от первого лица в женском роде: «проверила», «помогло».

## Когда писать

Проблема встретилась **второй раз** — или первая, но решение неочевидное (полчаса поиска).
Одноразовое не документируем: журнала достаточно.

## Файл

`docs/Памятки/<тема>.md` — по одной теме на файл: `диск-место.md`, `звук.md`, `vpn.md`, `принтер.md`,
`docker.md`, `vs-code.md`, `сеть-dns.md`.

## Формат

```
# Диск: место кончается

**Симптом:** «нет места», df показывает 90%+
**Диагноз:** df -hT; sudo du -xh --max-depth=1 /var | sort -h; docker system df
**Что помогло (2026-10-25):** docker image prune -a → освободилось 16 ГБ
**Проверка:** df -h / → 68%
**Грабли:** тома не трогала — там данные проектов
```

## Правила

- Симптом — словами руководителя (по ним памятку и найдут).
- Команды — готовые к копированию, с `sudo` отдельным блоком.
- В конце — «грабли»: что нельзя делать в этой ситуации.
- Ссылка из `MACHINE.md` (раздел «Памятки»), чтобы не искать по папке.
