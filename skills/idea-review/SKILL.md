# idea-review — оценка идеи

## Формат (3–5 строк)

1. **Что даёт:** ценность и KPI (кому и что станет лучше).
2. **Чего стоит:** грубая оценка чел-дней, инфраструктура, риски; какие решения нужны (решения, не задачи).
3. **MVP:** минимальный объём для проверки гипотезы (1–2 недели).
4. **Куда:** отдельный проект / задача в существующий (какой спринт) / отложить до условия.
5. **Проверка:** метрика + срок, по которым поймём, что сработало.

## Правила

- Сначала ценность, потом технология: идеи без KPI — переформулируем или отклоняем.
- Новая разработка → `project-bootstrap`; изменение стандарта студии → правка ядра + раскатка + `--check`.
- Оценки в чел-днях; помнить про RAM и число одновременно поднятых стеков.
- Идеи складываются в `03-Идеи/Воронка идей.md` (статус: оценка → MVP → проект / отклонена).
