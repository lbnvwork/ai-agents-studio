# Run-tests

Команды у каждого проекта свои — берутся из **варианта скилла для проекта** (порядок поиска):
`profiles/<project>/skills/run-tests.<код агента>.md` → `run-tests.<дорожка>.md` → `run-tests.md` → этот файл.

- Тесты и линтеры зелёные — обязательное условие перед PR. Падают — чини (не «пусть CI проверит»).
- Гоняй в контейнере проекта: `docker compose -p <проект> exec -T <сервис> sh -lc '<команда>'` (`-T` обязателен — терминал агента неинтерактивный).
- Результат прогона (`<тесты> OK (N tests)` · `<статик-анализ> OK` · `<линтеры> OK`) — обязательное поле отчёта и PR (секция «Тесты»).
- Локальный рантайм ≠ образ: сборка и тесты — в контейнере.
