# run-tests — единая команда проверок

## Главное правило

**Одна команда — `make ci`.** Не гоняй линтеры и тесты по одному: у проекта есть единая точка входа,
и она же используется в CI. Если `make ci` нет — работает fallback (ниже) и об этом пишем в отчёте.

```bash
make ci                # полный прогон: линтеры + тесты + сборка + метрики
make lint              # только линтеры/статический анализ
make test              # только тесты
make metrics           # покрытие, бюджет бандла
DRY_RUN=1 make ci      # показать, что будет выполнено, ничего не запуская
```

Что внутри `make ci` (пример веб-стека, задача 5.33): PHP CS Fixer · PHPStan · composer-unused · Deptrac ·
ESLint · Prettier · Stylelint · Knip · PHPUnit · Vitest · сборка фронта · метрики покрытия и бандла.
Жёсткий режим: **любое замечание = ненулевой код возврата**; шаги не прерываются, в конце — сводка
«упало N из M» и перечень упавших. Имя compose-проекта берётся из `.env`, `-p` не нужен.

## Fallback: если `make ci` в проекте нет

| Стек | Команды (в контейнере проекта, `-T` обязателен) |
|---|---|
| PHP/Symfony | `docker compose exec -T php sh -lc 'vendor/bin/phpunit'` · `… 'vendor/bin/phpstan analyse --no-progress'` · `… 'vendor/bin/php-cs-fixer fix --dry-run --diff'` |
| Node/Vue | `docker compose exec -T node sh -lc 'npm test'` · `… 'npm run lint'` · `… 'npm run build'` |
| Kotlin/JVM | `./gradlew build` (включая ktlint/detekt, если настроены) |

## Отчёт (обязательное поле)

- Успех: `make ci OK` (или `make ci OK: N шагов, T сек`).
- Падение: `make ci: упало 3 из 7 — phpstan, eslint, vitest` + ссылка на артефакты, если проект их пишет.
- Fallback: перечислить фактически выполненные команды и их результат.

## Правила

- Прогон — **до** передачи на коммит/PR; «пусть CI проверит» не принимается: CI — контрольная точка,
  а не замена локальному прогону.
- Локальный рантайм ≠ образ: всё в контейнере проекта.
- Нельзя «прогнать только свой линтер» и отчитаться: единая команда либо её отсутствие — фиксируем факт.
- Упавший шаг чинится, а не подавляется: отключение правила/теста — только с обоснованием и по решению Лида.
