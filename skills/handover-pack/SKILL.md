# handover-pack — передача проекта ПМ

## Пакет (5 документов)

| Документ | Где |
|---|---|
| **Старт РП (<project>)** — онбординг, чек-лист первого дня, открытые решения | `docs/09-Служебное/Инструкции/` |
| **Спринт-00 «реформа»** — 5–8 подготовительных задач (est/order/goal) | `docs/03-Задачи/Спринты/Спринт-00/` |
| **`.cline/context.md`** — конспект воркспейса ПМ | `<клон>/.cline/context.md` |
| **Промт ввода в курс дела** — заполнить значения | `templates/pm-onboarding-prompt.md` (ядро) |
| **Квитанция передачи** — состояние на момент передачи | ответ руководителю + строка в «Решения и риски» |

## Квитанция (обязательные пункты)

- Спринт, число задач, «ждёт меня / ждут агентов»; висящие PR и незапушенные коммиты агентов.
- Риски, которые нельзя потерять (решения, регуляторика, ПДн).
- Доступы: репозитории, контуры, порты, где `.env`.
- Что ПМ делает в первый день (раздел «чек-лист» из «Старт РП»).

## Проверки перед сдачей

- [ ] `setup.sh --check` = 0 · `check_meta` / `sprint_plan --check` без нарушений
- [ ] канарейки зелёные, `/health` отвечает
- [ ] все 5 документов на месте, ссылки живые
- [ ] ПМ знает про хук PreCompact и команду «синхронизируйся»
