# studio-artifact — мой раздел в проекте

Студийный агент владеет **одним разделом** в проектных доках: юрист — «Юридическое»,
безопасник — «Безопасность», медэксперт — «Клиническое». Внутри — только его материал.

## Что лежит в разделе

```
README.md          владелец · что здесь лежит · статусы · ссылка на студийный реестр
<Документ>.md      канон: шапка + текст; один документ — один файл
Приложения/        приложения к ТЗ, КП, договорам
Риски.md           правовые/безопасностные риски проекта со ссылками на задачи
```

## Шапка файла (обязательна)

```
---
type: legal | threat-model | attack-surface | clinical
owner: aug | nov | sep
status: черновик | на проверке | утверждён
version: 1.0
source: <первоисточник + дата проверки>      (для юридических — норма и дата)
updated: ГГГГ-ММ-ДД
---
```

## Границы

- Пишешь **только в свой раздел**. Статьи задач не правишь, карточки не двигаешь.
- Чужие разделы и разделы проекта («Аналитика», «Задачи», «Разработка») — только чтение.
- **Нельзя класть в git:** персональные данные, сканы с подписями, ключи и доступы, пароли, суммы и
  коммерческие условия. Для этого есть `09-Служебное/Доступы` (gitignored) или внешнее хранилище.
- Канон живёт в проекте. В студию дублировать текст не нужно — только ссылку из реестра.

## Коммит (единственное исключение из запрета)

Разрешён только при установленном хуке:

```bash
git -C <клон docs> config core.quotepath false
cp <agents>/toolkit/hooks/pre-commit-own-section.sh <клон docs>/.git/hooks/pre-commit
chmod +x <клон docs>/.git/hooks/pre-commit
```

Порядок: `git pull --rebase origin main` → правка → `git add <свой раздел>` → `git commit` →
`git pull --rebase origin main` → `git push`. Хук отклоняет любые пути вне раздела.
Разовая миграция каталогов — `git commit --no-verify`, и только руководитель.

## Отчёт

После пуша — **короткий пинг в чат**: «запушил <раздел>, хеш <abc1234>». Без пинга руководитель
не знает, что репозиторий сдвинулся, и команда работает по устаревшей копии.
В отчёте — блок `КОММИТЫ` названиями-командами; в студию — строка в реестр (`04-Юридическое/`,
`lazurit-sec/проекты/<проект>/`) со ссылкой на файл в проекте и статусом.
