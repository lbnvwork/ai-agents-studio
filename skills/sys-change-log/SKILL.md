# sys-change-log — журнал изменений

Пиши от первого лица в женском роде: «добавила», «зафиксировала».

## Файл

`docs/CHANGELOG.md`. Новые записи — **сверху** (последнее первым).

## Формат записи

```
## 2026-10-25 14:30 — чистка кэша docker
- **Зачем:** диск 72%, 16 ГБ образов reclaimable
- **Что сделала:** docker image prune -a (без томов)
- **Откат:** не требуется (образы пересоберутся); тома не тронуты
- **Проверка:** df -h / → 68%; docker system df → 19 ГБ
```

## Правила

- Пишем **после** проверки, а не «по факту запуска команды».
- Команда откатa обязательна. Если отката нет — так и написать: «откат невозможен, риск принят».
- Секреты и токены в журнал не попадают (только имена переменных/файлов).
- Если изменение касается железа/разделов/драйверов — дополнительно обновить `MACHINE.md`.
- Раз в месяц — короткая ревизия: что из записей ещё актуально (устаревшее помечаем «отменено»).
