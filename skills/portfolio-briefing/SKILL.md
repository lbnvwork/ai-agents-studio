# portfolio-briefing — сводка по портфелю

Запускается **по запросу руководителя** (утренняя сводка — когда он попросит), не по расписанию.

## Шаги

1. **Данные портфеля:** `09-Служебное/Скрипты/portfolio_sync.py --write` в докax студии — собирает
   проектную информацию в `01-Портфель/Дашборд студии.md` (или `--check` — только проверить актуальность).
2. **По каждому проекту** (из [[Реестр проектов]]):
   - план/факт: спринт, число задач, закрыто чел-дней, «ждёт меня / ждут агентов»;
   - git: незапушенное и незакоммиченное во всех репозиториях, висящие коммиты агентов;
   - дрейф правил: `setup.sh --layer <слой> --check` = 0;
   - риски: топ из «Решения и риски» проекта.
3. **Ресурсы машины:** `docker compose ls` (что запущено), свободная RAM, свободные порты диапазонов.
4. **Ответ:** таблица «проект · спринт · статус · ждут меня · ждут агентов · риски» + топ-3 действия.

## Правила

- Только чтение: сводка не двигает карточки и не правит статьи проектов.
- Детали проекта не дублируем — ссылаемся на сводку ПМ; ищем то, что «выше» проекта.
- Ресурсы — обязательный блок (RAM ограничена, лишние стеки гасим).
