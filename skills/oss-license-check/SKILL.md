# oss-license-check — лицензии и чужие материалы

## Политика студии (по умолчанию)

| Категория | Лицензии | Что делаем |
|---|---|---|
| **Разрешено** | MIT, Apache-2.0, BSD-2/3, ISC, 0BSD, Unlicense | используем, фиксируем в отчёте |
| **Условно** | LGPL-2.1/3, MPL-2.0, EPL-2.0 | только без модификации и с динамической линковкой/отдельным модулем; отметить в отчёте |
| **Запрещено** | GPL-2.0/3.0, AGPL-3.0, SSPL, CC-BY-NC, «non-commercial», «no derivatives» | не тащим в продукт; альтернатива или письменное решение руководителя |
| **Проверить отдельно** | проприетарные SDK (вендоры, ЭИБ, мессенджеры), бесплатные тарифы API | условия использования: лимиты, право на перепродажу, хранение данных |

Отдельно проверяем **не-код**: справочники (МКБ, регионы, ЛПУ), инструкции препаратов, шрифты, иконки,
фото, датасеты — у них свои лицензии, и «взяли из интернета» не основание.

## Как получить список (по стеку)

```bash
# PHP / Symfony
composer licenses --format=json            # или: composer licenses

# Node / Vue
npx license-checker --summary              # или: npm ls --all --json

# Kotlin / Gradle (JVM)
./gradlew :app:dependencies --configuration runtimeClasspath

# Python
pip-licenses --format=markdown --with-urls
```

Дальше: выбрать из вывода всё, что не в «Разрешено», и разобрать по таблице выше.

## Формат отчёта

Таблица: `пакет · версия · лицензия · категория · где используется · решение` + итог:
`блокеров: N` / `условных: M` / `проверить у юриста: K`.
Кладём в `docs/04-Юридическое/Комплаенс/<проект>.md`, отдельным разделом «Лицензии».

## Правила

- Скан — обязателен перед релизом и при добавлении крупной зависимости (не только «когда вспомним»).
- Найденный GPL/AGPL — **блокер**: не «оставим на потом», а заменить или согласовать с руководителем письменно.
- Версия лицензии важна: `LGPL-2.1` и `AGPL-3.0` — разные вселенные.
- Не выдумываем лицензию по названию пакета: смотрим `composer.lock` / `package-lock.json` / `LICENSE` в пакете.
- Спорные случаи (двойное лицензирование, «custom») — в список вопросов юристу.
