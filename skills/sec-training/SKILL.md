# sec-training — обучение

## Программа (6 модулей, 25 процессов)

| Модуль | Процессы | Практика на наших проектах |
|---|---|---|
| 1. Основы РБПО | 1, 2, 4, 5 | план РБПО + журнал обучения |
| 2. Требования и угрозы | 3, 6, 7 | модель угроз и поверхность атаки для ibs |
| 3. Код | 8, 9, 10, 11 | правила кодирования + первый прогон SAST |
| 4. Цепочка поставок | 12–17 | секреты, SCA, SBOM, проверка зависимостей |
| 5. Тесты и выпуск | 18–21 | release-чек-лист с security-гейтом |
| 6. Эксплуатация и аудит | 22–25 | реестр уязвимостей + внутренний аудит |

## Формат занятия (45 минут)

1. **Конспект** 1–2 страницы (в `docs/обучение/модули/`): что требует ГОСТ (с пунктами), как это выглядит у нас, что делать.
2. **Чек-тест** 10 вопросов (в конце конспекта, с ответами для проверки).
3. **Практика** — артефакт на реальном проекте (не упражнение «в вакууме»).
4. **Запись в журнал** `docs/обучение/Журнал.md`:

```
| 2026-10-27 | Макс | Модуль 1 · процессы 1,2,4,5 | конспект + тест 9/10 | `модули/М1-основы.md` |
```

## Правила

- **Журнал — это доказательство** (п. 5.2.3.3 ГОСТ: свидетельства, отчёты, документы о прохождении обучения). Без записи занятие не считается.
- Самообучение фиксируется так же: `| дата | Ной | самообразование · процесс 16 | конспект | … |`.
- Не «читаем и забываем»: каждый модуль закрывается практикой с артефактом в проекте.
- Ритм: 2 занятия в неделю; при пропуске — сдвиг, а не «два за один раз».
- Внешнее обучение (курсы с удостоверением) — только через организации, согласованные с ФСТЭК; роль Ноя — подобрать и подготовить заявку.
