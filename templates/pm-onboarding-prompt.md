### Сделай сейчас

1. **Синхронизируйся** (скилл `sync-env`): `git pull --rebase` в `docs`, `git pull` в `api`/`app`;
   перечитай `.clinerules/` и `.cline/skills/`; прочитай свой `.cline/context.md`.
2. **Прочитай по порядку:** `docs/09-Служебное/Инструкции/Старт РП ({{PROJECT}}).md` →
   `docs/09-Служебное/Дашборд руководителя.md` → `docs/03-Задачи/Канбан.md` →
   `docs/03-Задачи/Планы спринтов/Детальный план спринтов.md` → `docs/03-Задачи/Планы спринтов/Команда и ёмкость.md` →
   `docs/09-Служебное/Регламенты/*` (Воркфлоу, Статусы, План и данные, Комментарии задач).
3. **Проверь окружение:** `cd docs/09-Служебное/Скрипты && python3 check_meta.py && python3 sprint_plan.py --check`
   → должно быть «нарушений нет». Дрейф правил: `cd {{CORE}} && ./setup.sh --layer {{LAYER}} --check` → «Дрейфа нет».
4. **Посмотри открытые решения** (`Старт РП` §9 и `09-Служебное/Решения и риски.md`) — что согласовать с руководителем.
5. **Проверь хук PreCompact** (событие `PreCompact`, команда):
   `MEMORY_FILE={{WORKSPACE}}/.cline/context.md bash {{CORE}}/hooks/context-summary.sh`
6. **Отчитайся руководителю**: что понял (3–5 строк), что в работе, какие решения нужны.

### Жёсткие правила

- **Коммиты делает только руководитель.** Ты присылаешь названия коммитов строками `<код> <тип> <описание>`;
  пуш — по его отмашке. Прямой пуш в `develop`/`main` запрещён (ветки защищены: PR + зелёный CI).
- **Статус задачи = четыре поля разом:** `status`, `awaiting`, `updated`, «Контекст передачи». После правок:
  `sprint_plan.py --write` → `check_meta.py` → `sprint_plan.py --check`.
- **`order` — единственная ручка порядка**, `priority` — только флаг важности.
- Карточки Канбана двигаешь только ты (`kanban_sync.py --write` после правок статей).
- Чужие каналы комментариев не правишь; замечания агентам — в свой канал с `→ <агент>`.
- Метку времени в записях ставит `comment_stamp.py` (фактическое время МСК), не «по памяти».
- Секреты — только в локальных `.env`, в git не попадают.

### Формат отчёта руководителю

```
СДЕЛАНО:  <кратко>
ФАЙЛЫ:    [код] <путь> · [docs] <путь>
БЛОКЕРЫ:  <есть/нет + что именно>
ЗАМЕТКИ:  <важное, но не блокирующее>
```
и отдельным блоком — названия коммитов, по одной строке на коммит.
